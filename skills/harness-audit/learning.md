# learning.md — iteration log for `harness-audit`

One entry per audit round. The rubric (`../../references/rubrics/skill-improver-rubric.md`, E2)
requires this file for every high-use skill: an audit that never records what it learned repeats
the same findings forever.

Keep entries short. A round that changed nothing still gets an entry saying so — a quiet round is
evidence too.

## Entry shape

```markdown
## <YYYY-MM-DD> — <one-line subject>

**Hypothesis:** what you expected to find, before looking.
**Change:** what you actually did.
**Result:** the command output or the finding, quoted. Numbers, not adjectives.
**Refuted:** what the evidence killed. This line is the point of the file.
```
