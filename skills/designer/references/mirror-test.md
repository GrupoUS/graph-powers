# The mirror test

Move 5 of `designer`. Two tests, run on the direction contract before it leaves the direction
pass. Both exist because a plan can pass every rule in the SKILL.md body and still be the plan
that any brief in the category would have produced — the rules constrain values, and only a
comparison catches a default.

## 1. The any-brief test

Take the contract and change only the subject. A brief for a different product in the same
category — another fintech dashboard, another coffee roaster, another developer tool. Read the
contract again.

- Every line that still fits was not derived from the subject. It is a default.
- A default is **rewritten from the subject's world**, not softened. Softening — a slightly
  different cream, a slightly different serif — keeps the default and loses the confidence.
- Write what changed and why in the contract's `Mirror` line. A mirror line that says "nothing"
  on a structural direction is a sign the test was not run, not a sign the plan was original.

A worked example — the contract before and after, for a booking surface for a small
independent cinema. Only the lines the test changed are shown.

| Line | Before (fits any cinema) | After (fits this cinema) |
|---|---|---|
| World | "cinematic, dark, immersive" | the 1970s programme leaflets this cinema still prints: two-colour risograph, one typeface, dates set in a rigid grid |
| Palette | near-black, one red accent, white | paper `#F2EBDD`, riso blue `#1D4E89`, riso red `#D9412B`, ink `#1A1A1A` — the two-ink constraint is the point |
| Type | Inter display, Inter body | a grotesque with a condensed cut for the programme grid; body in the same family at text size, because the leaflet is one face too |
| Signature | full-bleed film still hero | the week's programme as a grid the reader scans by day and hour, before any still — the leaflet, not the poster |
| Motion | fade-up on every section | none on the grid; one moment on seat selection, where the choice happens |
| Mirror | — | before: dark + red + film still fit every cinema on earth. After: the leaflet is this cinema's own artefact; a multiplex could not use it. |

The category standard — dark, film still, red accent — stays on the table as the explicit exit,
played straight if the user takes it. What the test forbids is arriving there without deciding.

## 2. Remove one accessory

With the contract complete, remove one element that is not the signature and not load-bearing.
A second accent colour, a decorative divider, a hover effect on a non-interactive card, an
eyebrow, the third font.

- If the direction is weaker without it, put it back and say why it earns its place.
- If the direction is the same or stronger, it was decoration. Leave it out.

Run it once. Running it in a loop strips the direction to nothing; the point is a single
deliberate subtraction after a single deliberate addition — the signature.

## What the two tests do not cover

They do not check contrast, targets, focus or reduced motion. Those are the floor, held by the
project's design rule and verified by `/design § 4` and `§ 5`; a direction is not exempt from
them and is not credited for meeting them. And they do not pick between two directions that both
pass — that is the user's choice in move 4, made on the three-direction comparison.
