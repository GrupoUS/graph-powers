# Librarian On-Demand Rubric

Load for conflicting sources, security guidance, or multi-claim synthesis.

## Source priority

1. Official product/API documentation or normative standard.
2. Maintainer source repository, release notes, or security advisory.
3. Primary research or vendor engineering publication.
4. Reputable secondary analysis only to locate primary evidence.

## Conflict handling

- Compare version, publication date, platform, feature flag, and deployment surface.
- Prefer the source matching the requested version and current date.
- State whether the conflict is real, version-dependent, or terminology drift.
- Never average contradictory claims; preserve the uncertainty.

## Reproducibility ledger

Record focused query, source URL/title, publication or update date, supported
claim, and caveat. Avoid long quotations; paraphrase and link directly.
