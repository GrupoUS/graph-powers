# UI/UX Designer On-Demand Rubric

Load for full heuristic, AI-interface, or aesthetic-system audits.

## Usability

- Visibility of status; match with user language; control and reversibility.
- Consistency; error prevention/recovery; recognition over recall.
- Efficient primary paths, progressive disclosure, and useful empty states.
- Mobile reachability, scroll ownership, touch targets, and keyboard behavior.

## Accessibility

- Semantic structure, labels, focus order/visibility, contrast, zoom/reflow,
  target size, error association, live updates, reduced motion, and non-color cues.

## AI interfaces

- Set expectations about capability, latency, data use, and uncertainty.
- Preserve user input, expose progress/cancel/retry, cite or explain outputs where
  needed, support refinement, and separate suggestions from committed actions.

## Aesthetic system

- Typography, color, spacing, shape, imagery, motion, and density form one intent.
- Reject generic SaaS defaults only when they weaken hierarchy, identity, trust,
  or task completion. Preserve elements that already serve the user well.

Rank Critical, High, and Medium; include evidence and one highest-leverage win.
